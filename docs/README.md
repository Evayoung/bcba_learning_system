# BCBA AI Learning Assistant — Codex Build Kit

This kit gives Codex a small, ordered set of implementation tasks for a practical BCBA exam-preparation assistant built with FastHTML and FastStrap.

## How to use this kit

1. Open your project repository in Codex.
2. Copy `00_PROJECT_BRIEF.md` into the repository as `docs/PROJECT_BRIEF.md`.
3. Give Codex one prompt at a time from `CODEX_TASKS.md`, in order.
4. Require Codex to run tests and report changed files after each task.
5. Do not ask Codex to implement the entire product in one prompt.
6. Start using a small, manually checked subset of the book while the rest is being extracted.

## Suggested first milestone

The first usable milestone is: choose a TCO task → read a source-grounded explanation → answer a question → see the rationale → have the attempt saved.

## Important boundaries

- This is a study aid, not official BACB material or a guarantee of exam success.
- Use the sixth-edition TCO and the candidate's exam eligibility/version as confirmed requirements.
- Do not invent official questions, citations, answer keys, or extracted book content.
- Keep source page references for extracted content.
- Mark uncertain OCR and AI-generated questions as unverified until checked.
- Check the study manual's copyright/license terms before redistributing its extracted content or sending pages to third-party services.
- Never put API keys in source code or commit them to Git.
